# Method provenance

These sources motivate the rubric. The plugin combines ideas from them; it is not an implementation or benchmark reproduction of each framework. Read a source when its claim matters, not every time a skill runs. Refresh current domain facts separately.

| Contribution | Primary source | Limit |
| --- | --- | --- |
| Persistent hypotheses, experiments and propagated insights | [Arbor architecture](https://ruc-nlpir.github.io/Arbor/docs/how-it-works/) | Applying its state model to product/investing is an adaptation |
| Reflective revision and diverse candidate retention | [GEPA](https://arxiv.org/abs/2507.19457) | Evidence concerns evaluated prompt/task settings |
| Compare success/failure; retrieve experience | [ExpeL](https://arxiv.org/abs/2308.10144) | Additional reflection can harm learning |
| Curate an evolving playbook | [ACE](https://arxiv.org/abs/2510.04618) | Weak lessons can produce harmful context |
| Outcomes, opportunities, solutions, assumption tests | [Torres](https://www.producttalk.org/discovering-solutions/) | Practitioner methodology, not guaranteed growth |
| Mechanisms in historical cases | [Collier](https://polisci.berkeley.edu/sites/default/files/people/u3827/Understanding%20Process%20Tracing.pdf) | Diagnostic evidence is not randomization |
| Context, mechanism and outcome | [Realist evaluation guide](https://www.gov.uk/government/publications/the-magenta-book/supplementary-guide-realist-evaluation-html) | Conclusions remain conditional |
| Interacting ideas | [NIST experimental design](https://www.itl.nist.gov/div898/handbook/pri/section2/pri212.htm) | One-factor-at-a-time tests miss interactions |
| Metric and novelty traps | [Microsoft experimentation paper](https://www.microsoft.com/en-us/research/wp-content/uploads/2020/08/2017-08-KDDMetricInterpretationPitfalls.pdf) | Short-term local gains can mislead |
| Price expectations and value creation | [Counterpoint Global](https://www.morganstanley.com/im/publication/insights/articles/article_opportunitiesandexpectations_ltr.pdf) | Valuation depends on assumptions |
| Historical financial AI evaluation | [Bias position paper](https://arxiv.org/abs/2602.14233) | Model weights and retrieval can leak hindsight |
| Expensive defined search spaces | [Bayesian optimization tutorial](https://arxiv.org/abs/1807.02811) | Requires a useful objective and search space |

No source establishes universal superiority for this combined plugin. Prefer observed results and fresh transfer checks over method branding.
