# Method provenance

For the newer source-research, memory and agent-team evidence, read [recent research sources](${CLAUDE_PLUGIN_ROOT}/reference/research-sources.md). The shared research-and-recall cycle connects these methods rather than replacing their domain limits.

These sources motivate the rubric. The plugin combines ideas from them; it is not an implementation or benchmark reproduction of each framework. Read a source when its claim matters, not every time a skill runs. Refresh current domain facts separately.

Local copies of the cited papers and Arbor architecture page are indexed at [local paper index](${CLAUDE_PLUGIN_ROOT}/reference/papers/index.md) in the plugin references. Other linked practitioner/handbook pages remain web references. The archive records versions and extraction limits and is read on demand.
